# Shantanu Parkhande · Portfolio

A bold editorial hero, then an interactive portfolio: walk up to a concept car at sunset, open the door, take a seat, log in on the centre screen and explore.

- **Apps:** About, Experience, Skills, Projects, Education, Contact
- **Games:** Wire Fix (connect the bus wires to light the bulb) and ECU Blocks (falling blocks)
- **Deep links:** `#about`, `#experience`, `#skills`, `#projects`, `#education`, `#contact`, `#wire`, `#blocks`

## Photo intro (optional)
If `exterior.jpg` and `interior.jpg` sit next to `index.html`, the intro becomes a photo scroll-zoom. Without them, it uses the drawn car.

## Hosting
Settings → Pages → Deploy from a branch → `main` / root. The site appears at `https://shanty007.github.io/My-Portfolio/`.

Built with plain HTML, CSS and JavaScript. No build step.
